Twitch auf der Vita.
Wieder da.

Seit Twitch die alte API abgeschaltet hat, lädt die offizielle Vita-App nichts mehr. Dieser Server spricht die alte Sprache der App und übersetzt sie in die heutige Twitch-API. Live-Streams, VODs, Login und gefolgte Kanäle funktionieren wieder, und die App selbst bleibt unverändert.

Vita verbinden → Einrichtung Quellcode

01Anmelden

Der Login läuft über Twitch selbst. Dein Passwort gibst du nur bei Twitch ein, die Vita bekommt es nie zu sehen.

  1. Code holen

    Wähle in der Twitch-App auf der Vita Anmelden. Sie zeigt dir einen 6-stelligen Code.

    K7Q2MX

  2. Code eingeben

    Öffne am Handy oder PC {HOST}/activate und tippe den Code ein.

  3. Bei Twitch bestätigen

    Du landest bei Twitch. Dort meldest du dich an und gibst den Zugriff frei. Die Vita ist danach nach wenigen Sekunden eingeloggt.

Ein Code ist 30 Minuten gültig. Danach meldest du dich auf der Vita einfach neu an.

02Einrichtung

Die Vita muss ihre Twitch-Anfragen an diesen Server schicken statt an Twitch. Das übernimmt das Plugin tls_fixer, ein DNS-Server ist nicht nötig.

  • Gehackte Vita: HENkaku oder Enso, mit taiHEN
  • tls_fixer und iTLS sind installiert und in der config.txt eingetragen
  • Die Twitch-App (PCSB00878) ist installiert
  redirects.txt · tls_fixer download
# Twitch-App -> {HOST}
api.twitch.tv {HOST}
usher.twitch.tv {HOST}
usher.ttvnw.net {HOST}
usher.justin.tv {HOST}
# Statistik-Server: werden sofort beantwortet, damit die App nicht haengt
spade.twitch.tv {HOST}
api.mixpanel.com {HOST}

Trag diese Zeilen in die redirects.txt von tls_fixer ein, starte die Vita neu und öffne die Twitch-App. Die Startseite sollte jetzt laden. Der PSN-Login bleibt davon unberührt.

03Was geht – und was nicht

Fast alles, was die App früher konnte, funktioniert wieder. Ein paar Dinge hat Twitch selbst abgeschafft.

Funktioniert

  • Live-Streams: H.264 bis 720p, Standard 480p
  • VODs: Übertragungen und Highlights
  • Startseite, Top-Spiele, Spiele-Verzeichnis
  • Suche nach Streams, Kanälen und Spielen
  • Login und gefolgte Kanäle
  • Profile mit Followern, Aufrufen und Banner
  • Ohne Werbung, sofern der Server mit einem Turbo-Konto läuft
  • Vollbild und Kanal melden

Geht nicht

  • Chat: Den gab es in der Vita-App nie
  • Folgen und Entfolgen: Das hat Twitch per API abgeschafft
  • Login per QR-Code: Die App kann ihn nicht darstellen, deshalb gibt es den 6-stelligen Code
  • Kanal-Aufrufe sind die Summe der Video-Aufrufe, weil Twitch keinen Kanalwert mehr liefert

04So funktioniert es

Die App fragt weiter die alte Kraken-API (v5) an, so wie 2014. Der Adapter beantwortet diese Anfragen mit Daten aus der heutigen Helix-API und bereitet die Streams so auf, dass die Vita sie abspielen kann.

PS Vita Twitch-App, unverändert │ tls_fixer: api.twitch.tv, usher.* → {HOST} ▼ nginx :443 · RSA-Zertifikat · TLS-Cipher, die die Vita kennt │ ▼ Adapter Kraken v5 → Helix · Login per Device-Code · HLS-Proxy │ ▼ Twitch Helix-API · Streams und VODs

Der Code ist offen: {REPO_SHORT}. Dort steht auch, wie du einen eigenen Server aufsetzt.

05Häufige Fragen

Die App lädt endlos oder zeigt „Serververbindung gescheitert“.

Meist fehlt ein Eintrag in der redirects.txt, oder tls_fixer bzw. iTLS ist nicht aktiv. Prüf die config.txt und starte die Vita danach komplett neu. Oben rechts auf dieser Seite siehst du, ob der Server gerade erreichbar ist.

Der Code wird als „unbekannt oder abgelaufen“ abgelehnt.

Ein Code ist 30 Minuten gültig. Starte die Anmeldung auf der Vita neu und gib den neuen Code ein. Eine Verwechslung ist ausgeschlossen, denn 0/O und 1/I kommen in den Codes nicht vor.

Bekomme ich Werbung?

Hat der Server ein Konto mit Twitch Turbo hinterlegt, laufen die Streams ohne Werbung. Sonst blendet Twitch die üblichen Werbespots ein.

Ist mein Twitch-Konto sicher?

Dein Passwort gibst du nur bei Twitch ein. Der Server erhält von Twitch nur einen Zugriffsschlüssel mit den Rechten, die die App braucht, etwa für gefolgte Kanäle und Abos. Die Vita bekommt nur einen eigenen Sitzungsschlüssel. Den Zugriff kannst du jederzeit bei Twitch unter Einstellungen → Verbindungen widerrufen.

Geht das auch auf der PS3?

Noch nicht. Die PS3 hat kein tls_fixer und bräuchte dafür einen eigenen Umweg, das wäre ein eigenes Projekt.
